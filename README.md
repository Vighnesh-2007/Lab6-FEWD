# Experiment 6 – Student Result Management System

## Aim
To develop a web-based Student Result Management System using HTML, CSS, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Features
- Student name and roll number entry
- Marks entry for three subjects
- Automatic total and percentage calculation
- Grade calculation
- Pass/fail status
- Input validation
- Responsive user interface
- Clear form functionality

## Project Structure
```text
EXP6-Student-Results/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose Open with Live Server.
4. Enter student details and marks.
5. Click Calculate Result to display the result summary.

## Result
Successfully developed a web-based Student Result Management System using HTML, CSS, and JavaScript.

## Note
This is a front-end demonstration. Student records are not permanently stored in a database.
